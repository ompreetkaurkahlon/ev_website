# ⚡ ChargeBeam - Next-Gen Smart EV Charging Solutions

ChargeBeam is an interactive, modern web application and platform designed for turnkey, ultra-fast, and intelligent Electric Vehicle (EV) charging infrastructure. Engineered for commercial hosts, fleet operators, retail hubs, and highway destinations.

---

## ✨ Features

- **Interactive ROI & Revenue Calculator**: Estimate potential host earnings, annual profit, energy throughput, and payback period dynamically.
- **Station Locator & Live Status**: Filter charging stations by connector type (CCS2, CHAdeMO, Type 2, Megawatt), speed, and real-time availability.
- **Smart Fleet & Host Dashboard**: Comprehensive telemetry, load balancing, hardware status, and live transaction monitoring.
- **Hardware Showcase**: Detailed specifications for Level 2 AC Chargers, Ultra-Fast DC Fast Chargers (150kW–360kW), and Fleet Megawatt Charging Systems (MCS).
- **Responsive & Modern Design**: Built with a sleek dark-mode futuristic cyber-aesthetic, high contrast typography, glassmorphism UI components, and micro-interactions.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, Vanilla CSS3 (Custom Properties & Responsive Layouts), JavaScript (ES6+)
- **Icons**: Lucide Icons
- **Typography**: Google Fonts (*Outfit*, *Inter*, *Space Grotesk*)
- **Backend / Server**: Node.js micro-server (`server.js`)

---

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v16+ recommended)
- A modern web browser (Chrome, Edge, Firefox, Safari)

### Local Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/your-username/chargebeam-ev.git
   cd chargebeam-ev
   ```

2. **Run locally using static server or Node**:
   ```bash
   node new_ev/server.js
   ```
   Or open `new_ev/index.html` directly in your browser.
